## 🚀 How to Host This Portfolio on GitHub Pages (Free)

Hosting your portfolio on GitHub Pages takes only 2-3 minutes. Follow these simple steps:

### Step 1: Create a GitHub Account & Repository
1. Log in to [GitHub](https://github.com).
2. Click the **"+"** icon in the top right corner and select **"New repository"**.
3. Name your repository:
   - **Option A (Personal User Page)**: Name it `<your-username>.github.io` (e.g., `omkarangadi.github.io`).
   - **Option B (Project Page)**: Name it `portfolio` or `omkar-portfolio`.
4. Keep it **Public** and leave "Add a README file" **unchecked**.
5. Click **"Create repository"**.

---

### Step 2: Upload Files to GitHub

#### Method A: Using Git Command Line (Recommended)
Open your terminal inside this `omkar-portfolio` directory and run:

```bash
git init
git add .
git commit -m "Initial portfolio release for Omkar Angadi"
git branch -M main
git remote add origin https://github.com/<your-username>/<repository-name>.git
git push -u origin main
```

#### Method B: Using GitHub Web Interface
1. In your newly created GitHub repository page, click **"uploading an existing file"**.
2. Drag and drop all files (`index.html`, `styles.css`, `script.js`, `README.md`) into the web uploader.
3. Click **"Commit changes"**.

---

### Step 3: Enable GitHub Pages
1. Go to your GitHub Repository **Settings** tab.
2. On the left sidebar, click on **Pages**.
3. Under **Build and deployment** -> **Source**, choose **"Deploy from a branch"**.
4. Select **Branch**: `main`, Folder: `/ (root)`.
5. Click **Save**.

🎉 **Your website will be live in ~60 seconds** at `https://<your-username>.github.io/<repository-name>/`!
